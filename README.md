# Waystones Pets Addon
This mod lets your tamed pets automatically teleport with you when using Waystones—no leads required. It’s a simple way to keep your pets by your side as you explore.

## Why I Made This
While similar mods exist, I found them to be unreliable and buggy. After facing repeated issues, I reached out to the original mod’s creator. They mentioned they didn’t have access to the source code but would try to obtain it. However, since then, I’ve received no updates, so I decided to create my own solution.
